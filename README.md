# How I Use AI in Academia

A short presentation on how AI tools support teaching, research, and engineering work.

## Live tool

[Open How I Use AI in Academia](https://nuhaaljuneidi.github.io/AI/)

## Features

- Building physics tools for graduate courses.
- AI support for dissertation literature reviews.
- Python and machine learning for engineering.
- AI tools for engineering software.
- Interactive tools that create new student examples.

## Run locally

Open `index.html` in a modern browser. No build step is needed.
